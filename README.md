## 🛰️ Overview

Welcome to the repository for **Hari Krishnan P's** futuristic AI developer portfolio. Built with a cyberpunk heads-up display (HUD) aesthetic, this interface highlights cutting-edge engineering across **Generative AI, Agentic AI, Computer Vision (OpenCV), and Deep Learning Forensics**.

Rather than relying on heavy bloated UI templates or third-party cloud APIs, this portfolio showcases lightweight, ultra-responsive native engineering with **synthesized Web Audio**, **dynamic HTML5 canvas synapse networks**, **scroll-reveal observer animations**, and an embedded **holographic cyber chatbot assistant**.

---

## ⚡ Interactive Innovations

### 1. 🤖 Floating Cyber AI Chatbot (`HK//AI BOT`)
- **Compact Floating Widget**: Located in the bottom-right corner with a pulsing telemetry badge; does not take up vertical layout flow.
- **Natural Query Answering**: Instant conversational responses for work experience at Pantech, technical stack, peer-reviewed publications, and contact info.
- **One-Tap Quick Chips**: Jump directly into queries like `💼 Role`, `🚀 AI Projects`, `🎯 Core Skills`, `🔬 Publications`, and `📬 Contact`.
- **In-Chat Neural Forensics Simulator**: Executes an interactive multi-step deepfake media scan right in the chat stream with confidence scores and SHA-256 verification.
- **Cyber Audio Feedback**: Dynamic frequency chimes synthesized via the Web Audio API on message dispatch and receipt.

### 2. 🌌 Real-Time Neural Synapse Canvas
- Interactive particle network tracking mouse coordinates with real-time particle repulsion and kinetic neural connection lines.
- Dynamically resizes to any display resolution with optimized 60 FPS animation loops.

### 3. 📜 Hardware-Accelerated Scroll Reveal Engine
- Built with standard browser `IntersectionObserver` APIs.
- Section titles, biographical dossiers, experience timelines, project showcases, and research papers seamlessly glide into view with directional offsets and progressive timing delays (`.reveal-on-scroll`, `.reveal-left`, `.reveal-right`).
- **Animated Skill Meter Gauges**: Skill capacity bars smoothly expand from `0%` to their target thresholds upon entering the viewport.

### 4. 🎛️ Cyber Audio Synthesizer (Zero Asset Dependencies)
- Uses the browser's native **Web Audio API** to generate synthesized square, triangle, and sine wave chimes for button interactions and message prompts—no bulky `.mp3` or `.wav` sound files required.

## 🚀 Quick Deployment & Live Preview

Because this portfolio is built with zero heavy external build frameworks, it runs instantly in any modern web browser without compiling or bundling!

### Option 1: Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/HKhari20/Portfolio-hk.git
   cd Portfolio-hk
   ```

2. **Launch with any local HTTP server:**
   - **Python:**
     ```bash
     python -m http.server 8000
     ```
   - **Node.js (`npx serve`):**
     ```bash
     npx serve .
     ```
   - Or open `index.html` directly in your browser.

3. **Navigate to:** `http://localhost:8000`

---

### Option 2: Deploy to GitHub Pages (1-Click)

1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "feat: futuristic AI portfolio with cyber chatbot & scroll animations"
   git branch -M main
   git remote add origin https://github.com/HKhari20/Portfolio-hk.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select `main` branch and `/ (root)` folder, then click **Save**.
3. Your portfolio will be live at `https://hkhari20.github.io/Portfolio-hk/`!
